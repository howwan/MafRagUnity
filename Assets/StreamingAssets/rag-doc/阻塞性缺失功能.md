**_计划：实现阻塞性缺失功能（楼板模式 + 未发布变更提醒）_**

  

 **上下文**

  

 根据《三维可视化产品生态项目-产品设计V2.0-增量.md》，系统目前缺少两个核心功能

 ：

 1. **楼板模式（Slab**

 **Mode）**：前台用户可在2D平面图上查看楼层单元布局，点击单元查看详情

 2. **未发布变更提醒机制**：后台编辑项目后，在发布前通过Redis追踪变更模块，并在UI上

 提醒用户

  

 这两个功能是需求追踪矩阵中标记为 ✅ 但实际代码中未实现的核心需求（RQ-FE-03 和

 RQ-BE-02）。

  

 **探索发现**

  

 **现有架构关键信息**

  

 - **后端**：Spring Boot 4.0.3, Java 17, PostgreSQL+PostGIS, Redis, Spring Events

 - **前台**：Vue3+TresJS+Three.js, Pinia, Element Plus, Playwright E2E

 - **后台**：Vue3+Element Plus, Pinia, STOMP WebSocket, Playwright E2E

 - **Redis**：已配置 StringRedisTemplate，现有用途包括：编辑锁(lock:edit:project:{i

 d})、token黑名单、用户收藏

 - **Floor实体**：已有 planImage 字段存储平面图URL，但Unit实体只有3D

 Point坐标，**缺少2D多边形轮廓数据**

 - **事件系统**：各模块已使用 ApplicationEventPublisher 发布 domain events（如

 ProjectUpdatedEvent, UnitCreatedEvent 等）

 - **发布流程**：POST /projects/{id}/publish 会触发 WebSocket 通知并保存版本快照

  

 **设计方案**

  

 **功能一：楼板模式（Slab** **Mode）**

  

 **后端变更**

  

 1. **新增** **Unit.outlinePolygon** **字段**（数据库迁移）

   - 类型：String（JSON 文本存储 [[x1,y1],[x2,y2],...]）

   - 位置：com.vis.modules.space.model.Unit

   - 原因：现有 coordinates 是 PostGIS

 PointZ（3D单点），无法表示2D平面上的单元轮廓

   - 兼容性：该字段可为null，不影响现有3D渲染逻辑

 2. **新增** **DTO**

   - SlabPlanResponse：包含 planImageUrl 和 unitOutlines: List<UnitOutlineDto>

   - UnitOutlineDto：包含 unitId, unitNumber, polygon: double[][], status

 3. **新增** **API**

   - GET /api/floors/{id}/plan?mode=slab → FloorController

   - 实现逻辑：根据floorId获取floor.planImage，加载该floor的所有unit，过滤掉无o

 utlinePolygon的unit，组装响应

 4. **测试数据补充**

   - 在 TestUserInitializer 中为已有unit生成简单的矩形outlinePolygon（基于coord

 inates的x,z坐标偏移±0.8米形成矩形）

  

 **前台变更**

  

 1. **新增** **Panel** **类型**

   - src/utils/constants.ts：PANELS 新增 SLAB: 'slab'

 2. **新增** **LeftSidebar** **菜单项**

   - src/components/LeftSidebar.vue：新增"户型图"图标按钮，使用 MapLocation

 或自定义图标

 3. **新增** **SlabPanel** **组件**

   - src/components/panels/SlabPanel.vue

   - 功能：

       - 显示当前楼层的平面图（<img> 标签）

     - 使用 SVG 叠加单元多边形（<svg> 覆盖在图片上，使用 viewBox 保持坐标映射）

     - 多边形点击事件：弹出单元详情（复用现有的 Unit 详情展示逻辑，或通过 event

 触发场景中的单元选择）

     - 支持缩放/平移（使用 CSS transform scale + 鼠标拖拽，或简单 wheel 缩放）

   - 坐标映射策略：outlinePolygon 使用相对坐标（0-100范围或实际米数），SVG

 viewBox 与图片尺寸对齐

 4. **RightPanel** **集成**

   - src/components/RightPanel.vue：新增 slab 面板渲染，标题 "nav.slab"

 5. **i18n**

   - zh.json / en.json：新增 nav.slab、slab.title、slab.noPlan 等

 6. **API** **服务**

   - src/services/floor.ts：新增 getFloorSlabPlan(floorId: number)

 **兼容性考虑**

  

 1. **Unit.outlinePolygon** 为 nullable，不影响现有 3D 场景渲染

 2. **DraftTracking** 仅在项目状态为 live 时追踪，草稿项目不触发提醒

 3. **SlabPanel** 仅在楼层有 planImage 时显示平面图，否则显示 empty 状态

 4. **Redis** **Key** **TTL** 设置为 7 天，避免死数据堆积

 5. **坐标系**：SlabMode 的 polygon 使用与 3D

 场景一致的相对坐标系（以楼层中心为原点，单位米），SVG viewBox 使用固定 100x100

 的相对比例进行映射，保证不同尺寸图片的一致性
