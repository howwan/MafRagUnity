  后端改动

  新建文件：
  - dto/LockStatus.java — 锁状态 DTO（locked, lockedBy, lockedByUserId,
  expireAt, remainingSeconds）
  - service/EditLockService.java — Redis 编辑锁服务
    - getLockStatus() — 查询 Redis Hash，返回锁状态
    - acquireLock() — 获取锁（HSET + EXPIRE 1800s）
    - releaseLock() — 释放锁（校验持有者后 DEL）
    - renewLock() — 续期锁（校验持有者后重置 TTL）
    - Redis Key: lock:edit:project:{projectId} (Hash)
    
  修改文件：
  - controller/ProjectController.java — 新增 4 个端点：
    - GET /api/projects/{id}/lock-status
    - POST /api/projects/{id}/lock
    - DELETE /api/projects/{id}/lock
    - POST /api/projects/{id}/lock-renew
    
  后台 (admin) 改动

  修改文件：
  - src/api/project.ts — 新增 LockStatus 接口和 lockApi（4 个方法）
  - src/locales/zh-CN.ts / en.ts — 新增 5 个 lock 相关 i18n keys
  - src/views/project/edit.vue — 实现编辑锁轮询与只读模式： 
    - 30 秒轮询锁状态
    - 被他人锁定时显示 el-alert 提示条
    - 表单控件自动禁用（isReadOnly computed）
    - 编辑器自动设为只读（editor.setEditable()）
    - 剩余 < 2 分钟自动续期
    - 页面关闭/离开时自动释放锁（keepalive: true + onBeforeUnmount）
    
  新建文件：
